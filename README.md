HoopDesk – Basketball Tournament Management System A responsive, browser-based basketball tournament manager built with plain HTML, CSS, and JavaScript. It is ready for GitHub Pages. Files index.html – website structure style.css – design and responsive layout script.js – login demo, teams, matches, scores, standings, backup/restore Run locally Open index.html in a modern browser. No build tools or server are required. Demo login Username: admin Password: admin123 This is a demonstration login only. It is not secure authentication and must not be used to protect private information. Publish with GitHub Pages Sign in to GitHub and create a new repository, for example hoopdesk. Upload index.html, style.css, and script.js to the repository's root folder. Open the repository's Settings. Select Pages in the sidebar. Under Build and deployment, choose Deploy from a branch. Select branch main and folder /(root), then press Save. Wait for GitHub Pages to publish the site. Your address will look like: https://YOUR-USERNAME.github.io/hoopdesk/ Important notes Data is saved in the browser's Local Storage. It does not automatically sync between devices or users. Clearing browser data can erase saved tournament data. Use Settings → Download Backup (JSON) regularly. The standings use Win = 2 points, Draw = 1 point, Loss = 0 points. This project is a front-end demo. For secure accounts and shared multi-device data, a backend and real authentication are needed.
